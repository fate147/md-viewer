# 规格 01 · 启动与页面装载

> 类型：主规格（系统当前必须遵守的规则）｜建立：2026-10-26｜更新：2026-10-26（R-01-05 根因为同步树落点；R-01-06 报错吐真话；R-01-01 废除 CWD 条款并已删死代码；R-01-04 删除应用内 `.md` 关联注册条款）｜来源：排查报告《功能地图与风险点排查.md》

## 适用范围
应用进程从启动到页面就绪、初始内容装载、WebView2/STA/冻结运行时纪律、便携版运行时装配与启动失败可诊断性。覆盖 `src/main.pyw` 启动段、`src/ui/web_client.py` 就绪探测、`src/assets/app.html` 首屏。

## 必须遵守的规则

**R-01-01** 启动必须 STA：主线程在 `import tkinter`/`clr` 之前调用 `CoInitializeEx(STA)`（值 `0x2`）；Tk `mainloop` 必须留在主线程，禁止挪进 CLR 托管线程（会在 `dooneevent` 处触发 `PyEval_RestoreThread` 崩溃）。
- 依据：`main.pyw:377-383`、`:9-13`
- **迁移状态**：原「冻结模式必须 `chdir` 到 exe 目录」条款**已废除**（该归因错误，真因归 R-01-05）。对应死代码为两处不可达的 `getattr(sys, "frozen", False)` 分支（清理前位于 `main.pyw:75-76` 起守护线程、`:325-331` 的 `_auto_register`；便携分发下 `sys.frozen` 恒 `False`），**已于 2026-10-26 删除**。旧引用 `:398-405` 为失效坐标（清理前文件仅 398 行且无 `chdir` 块），**已废止，勿再引用**。

**R-01-02** 首屏三块（`tabbar`/`editor-host`/`reader`）初始 `hidden`，由 `app.js` 按状态显隐，不由 HTML 静态决定。
- 依据：`app.html:11-15`

**R-01-03** `__appReady` 之前不得下发任何下行桥方法（探测用 `_eval_core` 除外）；装载完成以 `__appReady` 为唯一信号，禁止用延时猜测就绪。
- 依据：`app.js:351`；`web_client.py:134-137`、`:364-371`

**R-01-04** 初始内容装载顺序固定：① 命令行 `.md` 参数（`main.pyw:96-100`）→ ② 会话恢复（`session.open_tabs`，**上限见 02 R-02-08**，本规格不重复写数字）→ ③ 欢迎页（`ui.welcome.WELCOME`，`main.pyw:109-113`）。
- 依据：`main.pyw:96-100`（命令行参数）、`:103-113`（会话恢复+欢迎页）
- **迁移状态（2026-10-26）**：原「冻结模式下在后台守护线程执行 `.md` 关联注册（`_auto_register`）」条款**已删除**——便携分发下 `sys.frozen` 恒为 `False`，该分支不可达；`_auto_register()` 与 `src/services/registry.py` 已一并删除。`.md` 关联注册归安装包，见下方禁止事项。

**R-01-05** 便携包落点约束（**根因已确认，2026-10-26**）：
`dist-app\MDViewer` 整包**禁止**存放在 Documents / OneDrive / 任何同步树内运行。该树是 OneDrive「已知文件夹」，.NET 的 `Assembly.LoadFrom` 在其中加载程序集失败，导致 `import clr` 必然抛
`RuntimeError: Failed to resolve Python.Runtime.Loader.Initialize from …\pythonnet\runtime\Python.Runtime.dll`。
- **正确处置**：整包搬到非同步路径再运行 / 打包 / 验证。项目既定落点 `%USERPROFILE%\Build\md-viewer\`（与安装器出包同一约定）；搬到该处后 `CLR_OK` 与窗口均正常（2026-10-26 实测）。
- **CWD 归因已彻底证伪**：三个判别实验（CWD=`app` / 应用根 / `runtime`）全部失败且报错完全一致；机制上也不成立——`clr_loader/ffi/__init__.py:49-61` 用 `ffi.dlopen(绝对路径)`，`clr_loader/netfx.py:38-44` 向 native 传 `str(Path(assembly_path))` 绝对路径。**禁止**再用「切 CWD」解释或修复该错误。
- 源码模式不受影响：`python src/main.pyw` 用的 `Python.Runtime.dll` 位于 `AppData\Local\Programs\Python\Python312\…`，不在同步树内。
- **出包前置闸**（三项全过才许可出包，任一失败即中止；**必须在非同步路径下执行**）：
  1. `runtime\python.exe -B -c "import clr; print('CLR_OK')"` → 输出 `CLR_OK`
  2. `runtime\python.exe -B -c "from tkwebview2.tkwebview2 import have_runtime; print(have_runtime())"` → `True`
  3. `runtime\python.exe app\main.pyw` → 窗口出现
- 打包必须记录 `runtime\BUILD-INFO.txt`（Python 精确版本 / `pythonnet` / `pywebview` / `tkwebview2`）；**禁止**手工剪枝 `Lib/site-packages` 而不留清单。
- `runtime\` / `app\` 及出包产物不得含 `python.exe.WebView2`、`pythonw.exe.WebView2`（本地用户数据，不得随包分发）。
- **已排除项（勿重复排查）**：`pythonnet/runtime/` 三文件、`clr_loader` 整树、`ClrLoader.dll`、`python312.dll`、`vcruntime140.dll` 与可用环境**逐字节一致**；`Lib` 仅少 `ensurepip`/`idlelib`/`test`；`DLLs` 逐文件一致；`Lib/site-packages` 剪枝只涉及 numpy/cv2/onnxruntime/PIL/rapidocr 等无关包。故「缺文件 / 版本不一致」不成立。
- 依据：`docs/archive/packaging.md:34-37`、`docs/log/2026-10.md:27`（Documents 毒性原始记录）；`clr_loader/netfx.py:38-51`、`clr_loader/ffi/__init__.py:49-61`；三 CWD 实验 + 搬家验证（用户实测，2026-10-26）

**R-01-06** 启动期能力检测必须报真话（禁止用「未检测到 WebView2」掩盖装配失败）：
- ① `web_client.py` 的 `webview_available()` 必须返回可区分原因的三元组 `(ok, reason, detail)`，`reason ∈ {"ok","missing","broken"}`；**禁止**裸 `except Exception` 只 `return False`。
- ② 任何检测失败必须把异常类型 + str + 完整 traceback 落盘到 `md-viewer-error.log`（`pythonw`/`winexe` 无控制台，**落盘是唯一可观测通道**）。
- ③ 「WebView2 未安装」与「已安装但运行时装配失败」必须**文案分离 + 退出码分离**：
  - `missing` → `EXIT_NO_WEBVIEW2 = 2`，提示安装 Evergreen Runtime（附注：若已装仍报此错，可能 .NET Framework < 4.6.2）
  - `broken` → `EXIT_RUNTIME_BROKEN = 3`，提示「运行时装配失败」+ 日志绝对路径，**禁止**出现「未检测到 WebView2」字样
- ④ 判定口径：`import clr` / `have_runtime()` **抛异常** → `broken`；**正常返回布尔** → `missing`。依据是 `have_runtime()` 自身不吞异常（`tkwebview2.py:141-143` 直接转发 `webview/platforms/winforms.py:44-95` 的 `_is_chromium()`）。
- 依据：`web_client.py:409-423`（`webview_available`）、`main.pyw:327-331`（`_log_path`）、`:333-337`（`_crash_log`）、`:339-375`（`_guarded`）；`tkwebview2.py:141-143`；`webview/platforms/winforms.py:44-95`

## 禁止事项
- 禁止在 CLR 托管线程里跑 `Tk.mainloop`（会触发 `PyEval_RestoreThread` 崩溃）。
- 禁止把便携包（`dist-app\MDViewer` 或已搬出的副本）放在 Documents / OneDrive / 任何同步树内运行或验证（见 R-01-05）。
- 禁止用 CWD 解释或修复 `Failed to resolve Python.Runtime.Loader.Initialize`（已证伪，见 R-01-05）。
- 禁止运行时缺失时仍尝试建 WebView2 控件。
- 禁止启动期能力检测吞异常不落盘，禁止用同一句「未检测到 WebView2」覆盖装配失败（见 R-01-06）。
- 禁止在 `__appReady` 之前下发业务下行桥调用（启动期调用 `request_text`、ready 前推 `set_tabs` 均禁止）。
- **禁止在应用进程内做 `.md` 关联注册**。便携分发下 `sys.frozen` 恒为 `False`（见 R-01-05），任何 `frozen` 分支都不可达；其依赖的 `installer/legacy/mdviewer_reg.py` 已于 2026-10-26 删除。关联由安装包调用 `installer/mdviewer-assoc.exe --install/--uninstall` 全权负责（`mdviewer.iss:45,51`），登录守护由 `mdviewer-assoc.cs` 写 `Run\MDViewerAssoc` 承担（`mdviewer-assoc.cs:427`）。
