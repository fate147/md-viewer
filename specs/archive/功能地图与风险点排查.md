## 1. 项目类型说明（重要前提，避免误读）

- 架构：**WebView2 单页双态**（2026-10-11 重构）。一个 `app.html` 页面内同时常驻「编辑层 CodeMirror6」与「阅读层 marked+hljs」，F2 同页显隐切换；Tk 只做窗口壳（菜单/状态栏/文件对话框）。
- **文本缓冲权威在浏览器**（`app.js` 的 `state.docs[id].st`），Python 只存标签元数据（`core/session`）。落盘/复制/导出经桥异步拉全文。
- 没有 `method+path` 式接口。"接口"在本项目 = **Python→JS 桥方法**（下行）与 **JS→Python 桥事件**（上行），由 `main.pyw._on_web_event` 作为唯一"路由派发器"。

## 4. 跨模块共享的高风险代码

> 评级：🔴 高（跨语言/状态机/历史出过同类 bug）｜🟠 中（强耦合/漂移）｜🟡 低（环境/多端一致）。

### 🔴 R1 · 桥协议 `ui/web_client.py` ⇄ `assets/app.js`
- **文件:行**：`web_client.py:32-38`（常量 `_CHUNK=100_000`/`_POLL_MS=120`/`_CALLBACK_TIMEOUT_S=5`/`_CALLBACK_RETRIES=2`）、`:127-291`（下行/上行）、`:331-351`（超时重发）；`app.js:323,341,346,351`（`__drain/__getTextMeta/__getTextChunk/__appReady`）。
- **被引用位置**：`main.pyw:90,92,245,249,265,276,284`；`actions.py:36,51,111,121,154,171,201`；`main_window.py:81,114`。
- **风险原因**：① 异步分块 + 超时重发状态机（`request_text` 单在途 + 队列，`:221-291`），任一回调错位即**永久卡死或丢内容**；② **双源真相**：Python `sess` 与 JS `state.docs` 各自维护"哪些标签存在"，靠 `app.js:214-220` `setTabs` 对账，不一致→**标签内容变空**（历史 bugs/004 同源）；③ **文档与代码不符**：`app.js:4` 注释写"256K 分块"，实际 100K。

### 🔴 R2 · `id(tab)` 跨语言主键
- **文件:行**：`main.pyw:43`（`self._loaded:set[int]`）、`actions.py:33,50,111,121,135,154,165,171,201`；桥侧 `tab_id` 整数贯穿 `web_client.py`；JS 侧 `state.docs` Map 键（`app.js:21`）。
- **被引用位置**：同上全栈。
- **风险原因**：依赖 **Python `id()` 不被复用**。标签关闭后对象被 GC，新建对象可能复用同一 `id()`，而 JS 旧 doc 未清理 → **内容错位 / 误判已装载**。`_loaded` 与 `state.docs` 是两套并行"已装载"真相，须始终一致。

### 🟠 R3 · `core/session.py`（TabState / Session）
- **文件:行**：`session.py:15-32`（`TabState`，含死字段 `cursor:22`、`title:30-32`）、`:35-110`（`Session`，含死方法 `mark_dirty:93-94`）、`:60 open_tab`、`:78 close_tab`、`:98 to_config`、`:105 restore`。

## 5. 排查结论

### 5.1 Bug 高发区（按证据排序）
1. **桥协议 + 标签生命周期**（R1+R2+R7）：历史 4 个 bug（001 预览滚动崩溃、002 替换不可撤销、003 大纲光标不动、004 关闭标签后内容变空）**全部落在这一带**，且 v3 仅换了实现（Tk→JS），**风险模式未消除**——双源真相 + `id()` 主键仍是隐患。
2. **文件保存/关闭/退出**（R6+R7）：异步拉文本 + 原子写 + 编码回写，任一环节竞态即丢数据。
3. **配置漂移**（R4）：死字段持续落盘，长期累积误导。

### 5.2 耦合最重处
- **`id(tab)` + `state.docs` + `sess`** 三者构成跨语言"标签真相"铁三角，任何一侧改动都必须联动另两侧——是**全局最高耦合点**。
- **`css_vars()`** 同时喂前端主题与导出，是颜色维度的枢纽耦合。

### 5.3 最该优先拆规格（建议 8 个，呼应 SDD 第二步）
1. `specs/05-桥协议（Python↔JS）.md` ← **最高优先级**，把分块大小/轮询/超时重发/双源真相一致性**固化为契约**，杜绝"注释说 256K"式漂移。
2. `specs/02-文件与标签生命周期.md` ← 与 R1/R2/R7 强绑，需明确 `id(tab)` 主键契约与缓冲同步规则。
3. `specs/03-编辑⇄阅读双态与排版.md`
4. `specs/01-启动与页面装载.md`
5. `specs/04-主题与样式系统.md`（R5 契约）
6. `specs/06-配置与持久化.md`（R4：清理死字段的硬规则）
7. `specs/07-导出与复制纯文本.md`（R9 slug 同源）
