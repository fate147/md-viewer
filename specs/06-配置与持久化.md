# 规格 06 · 配置与持久化

> 类型：主规格（系统当前必须遵守的规则）｜建立：2026-10-26｜更新：2026-10-26（补 R-06-02 DEFAULTS v3-only + 审校：原子写限定/上限10/行号）｜来源：排查报告《功能地图与风险点排查.md》

## 适用范围
`.md-viewer-config.json` 读写、默认值合并、死字段治理、`recent_files`、`session` 持久化。覆盖 `src/core/config.py`、`src/core/session.py`、`src/actions.py`（存档相关）。

## 必须遵守的规则

**R-06-01** 配置读写经 `core.config.load`/`save`；写入采用原子写（临时文件 + `os.replace`），崩溃不损坏配置。**原子写只保证不损坏文件，不保证不丢键**；是否保留用户已有键由 R-06-03③ 的保留式合并单独约束，二者不得混为一谈。
- 依据：`config.py:58-98`（`:58-71` 原子写、`:76-87` load、`:90-98` save）

**R-06-02** `DEFAULTS` **只含 v3 真实使用字段**（`theme`/`window`/`layout.reading_mode`/`font`/`auto_save`/`recent_files`/`session`）；禁止为已废弃能力（如 `preview_ratio`/`sidebar_visible`/`view_mode`）保留默认值。
- 依据：排查报告 R4；`config.py:31-40`

**R-06-03【死字段治理】** `preview_ratio` / `sidebar_visible` / `view_mode` 三个 v2 残留字段执行“三不”：① **不读**（不参与任何逻辑判断）；② **不再写**（DEFAULTS 及任何新写入不得包含它们）；③ **不主动删用户已有键**（用户配置文件中已存在的键须保留，禁止覆盖式重写导致丢失）。
- **读失败降级**：`save` 读现有文件失败（文件不存在 / 解析失败）时，降级为 `existing = {}` 继续写；**禁止因读失败而中止保存或丢数据**。
- 依据：排查报告 R4、D3；`config.py:34`；`.md-viewer-config.json:10-14`
- **迁移状态**：`save` 自身不读现有文件；当前 4 个调用点均传完整 dict，实际不丢键；保留式合并是加固，防未来 partial 调用

**R-06-04** 新增配置键必须先改本规格再改代码（“先改规格，再改代码”）。
- 依据：`config.py:31-40`（DEFAULTS）、`:76-87`（load 合并）、`:90-98`（save 合并）

**R-06-05** `recent_files` 上限 10（`actions.py:225` 的 `recent[:10]`）、去重（`actions.py:223-224` 排除当前路径后前插）、仅记录有 `path` 的标签（`actions.py:221`）；菜单刷新与之同步（`actions.py:227`）。
- 依据：`actions.py:219-227`（上限 `:225`、去重 `:223-224`、有 path 才记 `:221`）；`config.py:38`
- 【待确认：`.md-viewer-config.json:25` 的 `recent_files` 项指向根目录 `PRODUCT.md`，该文件现已不在根目录（见 `docs/archive/PRODUCT.md`），是否悬空/需清理待确认】

**R-06-06** `session` 持久化只存 `open_tabs`（路径列表）+ `active_tab`，**不存文本**；恢复只读路径、按需装载。
- 依据：排查报告 R3/R2；`config.py:39`；`session.py:98-110`；`main.pyw:107-112`、`:243-244`
- **与 02 咬合**：`session` 恢复数量上限只在 **02 R-02-08** 定义，本规格不重复数字；`recent_files` 规则以本规格 R-06-05 为唯一源，02 只引用。

## 禁止事项
- 禁止读取死字段（R-06-03①）。
- 禁止在 DEFAULTS 继续保留死字段用于写入（R-06-02/R-06-03②）。
- 禁止覆盖式合并导致删除用户已有键（R-06-03③）。
- 禁止 `session` 持久化写入文本（R-06-06）。

## 与其它规格的依赖
- 被 **02-文件与标签生命周期** 依赖（`recent_files` 以本规格 R-06-05 为源；`session` 数量上限以 02 R-02-08 为源，本规格不重复）。
- 被 **04-主题与样式系统** 依赖（`theme`/`font` 字段持久化）。
- 与 **05-桥协议** 无直接耦合（配置不含桥常量）。
