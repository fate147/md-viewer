## 适用范围
`.md-viewer-config.json` 读写、默认值合并、死字段治理、`recent_files`、`session` 持久化。覆盖 `src/core/config.py`、`src/core/session.py`、`src/actions.py`（存档相关）。

## 必须遵守的规则

**R-06-01** 配置读写经 `core.config.load`/`save`；写入采用原子写（临时文件 + `os.replace`），崩溃不损坏配置。**原子写只保证不损坏文件，不保证不丢键**；是否保留用户已有键由 R-06-03③ 的保留式合并单独约束，二者不得混为一谈。
- 依据：`config.py`（原子写 load save）

**R-06-02** `DEFAULTS` **只含 v3 真实使用字段**（`theme`/`window`/`layout.reading_mode`/`font`/`auto_save`/`recent_files`/`session`）；禁止为已废弃能力（如 `preview_ratio`/`sidebar_visible`/`view_mode`）保留默认值。
- 依据：排查报告 R4；`config.py`

**R-06-03【死字段治理】** `preview_ratio` / `sidebar_visible` / `view_mode` 三个 v2 残留字段执行“三不”：① **不读**（不参与任何逻辑判断）；② **不再写**（DEFAULTS 及任何新写入不得包含它们）；③ **不主动删用户已有键**（用户配置文件中已存在的键须保留，禁止覆盖式重写导致丢失）。
- **读失败降级**：`save` 读现有文件失败（文件不存在 / 解析失败）时，降级为 `existing = {}` 继续写；**禁止因读失败而中止保存或丢数据**。
- 依据：排查报告 R4、D3；`config.py`；`.md-viewer-config.json`
- **迁移状态**：`save` 自身不读现有文件；当前 4 个调用点均传完整 dict，实际不丢键；保留式合并是加固，防未来 partial 调用

- 依据：`config.py`（DEFAULTS）（load 合并）（save 合并）

**R-06-07【目录侧栏配置】**（2026-11-01 建立，2026-11-05 修订）
- `DEFAULTS.layout` 新增两个字段：`toc_visible`（布尔，默认 `true`）、`toc_mode`（`auto|always|never`，默认 `auto`）。
- `auto` 语义：**书卷模式显示；文档模式按大纲条目数决定**——`MDV.outline` 条目 ≥ `DOC_TOC_MIN=6` 时显示，短文档隐藏。长文档需要目录导航，短文档直接展示内容。
- 判定复用 03 R-03-05 的 `detectDocMode` 与 `reader.js` 的 `MDV.outline`；本规格只定义 `DOC_TOC_MIN` 阈值。
- **逃生阀（本规格要求）**：`auto` 被误判时，用户必须能手动强制显示目录（菜单复选与 `Ctrl+Shift+O` 均可），且该手动状态写入 `toc_visible` 后**不得被下一次 `auto` 判定覆盖**；即 `toc_mode=auto` 且 `toc_visible` 被用户显式设置过时，显示状态以 `toc_visible` 为准，`auto` 只决定默认值。
- 二字段纳入 R-06-02 白名单；写入走 R-06-01 既有原子写；读失败按 R-06-03 降级规则处理。
- **启动下发 ≠ 用户手动（2026-11-02 修正）**：
  启动时下发的 `toc_visible` **只是「给定初始状态」**，
  **不得**被 JS 侧记成「用户手动强制显示」的粘性标志。
  修前缺陷：`setTocVisible(true)` 同时设 `manual=true``并写 localStorage`，
  而 `manual===true` 会让 `shouldShow()` 直接返回 true、跳过 auto 判定 ——
  结果启动时的配置下发被误当成「用户点了显示」，**文档模式从此也一直显示目录**，
  且该错误状态被持久化到 localStorage，重装都清不掉。
  修正：新增独立的初始化通道（`initTocVisible(visible)`），只设显示状态、不写 manual；
  只有菜单 / `Ctrl+Shift+O` 才走 `setTocVisible()`（用户手动，粘性）。

- **逃生阀语义（2026-11-01 实测定稿）**：只有「**手动显示**」是粘性的——一旦用户手动显示，后续 auto 判定（含文档模式）都不得再隐藏它。**「手动隐藏」不是粘性状态**，它只作用于当前模式；切回书卷模式时 auto 照常恢复显示。否则用户在文档模式隐藏一次后，回到书卷也永远看不到目录，与「auto 只决定默认值」的本意相悖。
- **`toc_mode` 三值语义（2026-11-02 明确）**：`auto`=书卷显示 / 文档隐藏（默认）；`always`=始终显示（无视 auto）；`never`=始终隐藏。优先级：手动覆盖（`manual`）> `toc_mode`（always/never）> `auto`。`toc_mode` 由 Python 经新桥方法 `set_toc_mode` 下发；菜单入口「视图 → 目录显示模式」（auto/always/never）经 `App.set_toc_mode` 持久化并下发。**用户从菜单选择模式时须清除 `manual`/`configHide` 覆盖（clear_manual），令所选模式立即生效；启动下发不得清除**（否则每次启动会抹掉用户偏好）。
- **手动状态三态（2026-11-02 修正）**：`manual ∈ {true,false,null}`。`true`=手动显示（粘性、最高优先）；`false`=手动隐藏（**只作用于当前排版模式**：同一 doc/book 模式下持续有效，排版模式切换时复位为 `null`）；`null`=无手动覆盖。修前 `setTocVisible(false)` 把 `manual` 置 `null`，导致书卷模式下下一次 `refreshToc` 立即把目录重新显示、且启动时 `toc_visible=false` 被忽略；现 `false` 亦持久化并生效。
- **启动下发尊重 `toc_visible`（2026-11-02 补充）**：`initTocVisible(defaultVisible)` 在 `manual===null` 时，若 `defaultVisible===false` 必须直接隐藏（尊重配置里显式关闭），且记为**持久关闭**（`configHide`），不因后续 auto 刷新被覆盖，直到用户再次手动切换目录；若 `true` 则交给 `toc_mode`/auto 判定。禁止把启动下发 `true` 记成「用户手动显示」粘性标志（见上条 2026-11-02 修正）。
- **迁移状态**：**已同步（2026-11-02）**——`config.py` DEFAULTS 含 `toc_visible/toc_mode`；`toc.js` 落地 `manual` 三态 + `tocMode` + `setTocMode` + 窗口缓存失效；`web_client.py` 增 `set_toc_mode`；`main_window.py` 视图菜单加「目录 Ctrl+Shift+O」复选；`main.pyw` 启动下发 `toc_mode` 与初始显示状态。
- 依据：`config.py`（`layout` 现仅 `reading_mode`）；`specs/03` R-03-05
