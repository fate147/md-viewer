## 第一部分 · 视觉法：纸间微光

> 原 `docs/DESIGN.md`｜最后更新：2026-10-11（v3.0 单页双态口径）

### 创意北极星

**「纸间微光」**——安静、温暖、专注的 Windows 桌面 Markdown 阅读与写作工具。
设计哲学是「消失的设计」：界面的存在是为了被遗忘，只留下内容本身。
拒绝 IDE 密集工具栏，拒绝笔记应用的块编辑器/数据库/插件体系。

### 双排版模式（2026-10-11 起，核心机制）

同一份内容按文档形态自动选择排版，`layout.reading_mode`（auto|book|doc）可手动锁定，
判别规则：**代码围栏数 + 表格数 ≥ 2 → 文档模式**（阈值实现见 03 R-03-05 / `reader.js:106`）。

| | 书卷模式（默认：小说/散文） | 文档模式（技术文档） |
|---|---|---|
| 正文字体 | Georgia + 思源宋体/宋体（衬线） | Segoe UI + 微软雅黑（无衬线） |
| 对齐 | 两端对齐 + 段首缩进 2em | 左对齐、无缩进、段距 0.9em |
| 行高/版心 | 2.0 / 36em | 1.75 / 40em |
| 代表内容 | 《鬼探实录》等中文章回 | 本项目 `specs/` 下的技术文档 |

### 阅读层（书卷模式）排版细则

- 标题梯级 h1 1.75em（居中）/ h2 1.38em（下划线分隔）/ h3 1.18em；上下间距 ≈ 2:1
- 代码块：pre-bg 底 + 1px 边框 + 8px 圆角，悬浮工具条（语言标签 + 复制按钮）
- 表格：th 主题底色 + 斑马纹（quote-bg 55%）；宽表横向滚动
- 引用块：3px 强调色左边线 + quote-bg 底（既定识别，不受"细边线"通则约束）
- hr 居中短线 88px；链接下划线 1px + offset 3px；行内 code 药丸样式
- `text-autospace: normal` 中西文自动间隙（渐进增强）

#### 中文排版数值表（2026-11-01 起，v3.1）

| 项 | 取值 | 实现层 |
|---|---|---|
| 段首缩进 | 2em（排除列表、引用、表格单元格、标题后首段） | CSS（既有） |
| 避头尾 `line-break` | `strict` | CSS |
| 标点挤压 `text-spacing-trim` | `space-first` | CSS；不支持则静默跳过 |
| 中西文间距 `text-autospace` | `normal`（渐进增强） | CSS |
| 省略号 / 破折号 | **只做样式层，不改写字符** | CSS |
| 数字与单位 | 不插入任何不可见字符 | — |

### 卷/章节结构识别（小说排版分层）

> **词表覆盖（2026-11-01 实测）**：当前仅识别「第X卷/部」「第X章/节/回」；
> **楔子、序章、序幕、尾声、终章、番外、后记均无法识别**，扩充规则见 `specs/03` R-03-13。

全文无 markdown 标题且含「第X卷/部」「第X章/节/回」独立行时自动提升：
卷 → h2 居中加大加粗（字距 0.12em）、章 → h3 左对齐加粗、首个内容行 ≤30 字 → 书名 h1。
编辑器对同款行做整行加粗装饰。规范 markdown 文档不受影响。
（识别必须同源，规则见 03 R-03-04）

### 编辑层（CodeMirror 6）

- 字体跟随配置 `font.size/family`（默认 Georgia 17px + 雅黑），行高 1.9，版心 42em 居中
- 语法配色全部走 CSS 变量：标题分级放大（1.5/1.3/1.15em）、强调色仅用于列表标记与链接、
  meta（`##`、`**` 标记符）弱化为 muted；无行号、无活动行底色（消失的设计）
- 卷/章行整行加粗（与阅读层识别同源）

### 四主题（css_vars 体系）

颜色唯一数据源 = `core/theme.py css_vars()`（机制规定见 04 R-04-01）；运行时经桥下发 `setTheme`；
编辑层与阅读层同吃一套变量，Tk 外壳（状态栏/菜单底色）同步。切主题瞬时生效、无需重渲。

| ID | 名称 | 氛围 | 强调色 | 背景 | hljs |
|---|---|---|---|---|---|
| paper | 温润纸白 | 暖调日间，琥珀点缀 | #d4a373 | #fdfbf7 | light |
| midnight | 深夜墨黑 | 暗色夜间，翡翠点缀 | #4ec9b0 | #1e1e1e | dark |
| forest | 森之息 | 自然浅色，鼠尾草绿 | #6b8f71 | #f4f7f6 | light |
| pure | 极简纯白 | 高对比极简，GitHub 蓝 | #0366d6 | #ffffff | light |

**「单一声音」规则**：任何一屏强调色占比 ≤5%。
**对比度**：全部主题正文对背景 ≥ WCAG AA（4.5:1）。

### 层级与材质

平面风格，深度靠色调分层：内容层 → 1px 发丝分割线（`--divider`）→ 状态栏/标签条；
唯一浮层 = CodeMirror 搜索面板与对话框。不用盒子阴影、不用渐变、不用毛玻璃。

### 字体栈速查

- 阅读正文（书卷）：`Georgia, 'Times New Roman', 'Source Han Serif SC', 'Noto Serif SC', SimSun, serif`
- 文档模式/UI：`'Segoe UI', 'Microsoft YaHei UI', system-ui, sans-serif`
- 代码：`'Cascadia Mono', Consolas, 'Courier New', monospace`
- 编辑器：配置 `font.family`（Georgia）+ 微软雅黑兜底

### 该做与不该做

**该做**：留白充裕；强调色克制；衬线给阅读、无衬线给界面与文档；静默自动保存；
浏览器原生表面（滚动条/选区）主题化；`prefers-reduced-motion` 全局尊重。

**不该做**：IDE 式密集工具栏与状态面板堆叠；块编辑/数据库/插件体系；装饰性
渐变文字/毛玻璃/侧边条纹；数字章节标记与全大写眉题；暗色主题用纯黑背景；
任何让内容退居次位的动效与装饰。

## 第二部分 · 产品口径（需求书）

> 原 `docs/requirements.md`｜最后更新：2026-10-11（v3.0 口径重写）

### 产品定位（v3.0）

**MD Viewer —— 无干扰的 Markdown 阅读与写作工具（Windows 桌面）**

- 阅读：纸间微光排版（衬线/四主题/卷章分层），大文件流畅（2.3MB 实测全链路秒级）
- 编辑：CodeMirror 6 源码编辑（语法配色、查找替换正则面板），与阅读同页 F2 秒切
- 交付：单文件安装器（内嵌 WebView2 运行时），装完即接管 .md 关联

用户是作家、开发者、用 Markdown 记笔记的人；场景是安静无干扰的长文阅读与写作，
工具隐入背景。成功标准：用户忘记自己在用软件，注意力全在内容上。

### 验收五步（沿用 R2.1）

入口存在 → 操作可达 → 结果可见 → 数据落盘/生效 → 错误有反馈。
