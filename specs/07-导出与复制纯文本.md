# 规格 07 · 导出与复制纯文本

> 类型：主规格（系统当前必须遵守的规则）｜建立：2026-10-26｜更新：2026-10-26（补 R-07-03 plain_text 唯一 + 审校：slug 同源写明双份实现）｜来源：排查报告《功能地图与风险点排查.md》

## 适用范围
导出独立 HTML、复制纯文本、slug/锚点同源。覆盖 `src/services/export.py`、`src/services/plain_text.py`、`src/actions.py`（导出/复制入口）、`src/assets/reader.js`。

## 必须遵守的规则

**R-07-01** 导出 HTML 经 `services.export.to_html`，内联 `marked`/`hljs`/主题 CSS，写出的 `.html` 双击即可在浏览器打开，无运行时依赖。
- 依据：`export.py:73-96`

**R-07-02【slug 同源】** 导出所用标题 `slug` 规则必须与阅读层 `reader.js` 的 `slug` **完全一致**（保证目录/锚点对齐）。保证方式：当前为**双份实现**——`reader.js:11-14` 与 `export.py:49-52` 各一份完全相同的正则/实现（跨 Python/JS 无法共享常量）；改动须两端同步，并在 `specs/changelog.md` 登记「双份实现 + 两端行号 + 改动同步」。若未来改为共享常量，须同步更新本条。
- 依据：排查报告 R9；`export.py:49-52`；`reader.js:11-14`

**R-07-03** `plain_text.py:21-31` 的去标记正则为**唯一纯文本规则**；禁止在别处另写一份 Markdown→纯文本转换。
- 依据：`plain_text.py:21-31`

**R-07-04【导出 hljs 明度】** 导出所选 hljs CSS 必须与主题 `__hljs` 一致（`midnight → dark`，其余 `light`）。
- 依据：排查报告 R5；`export.py:75-76`；`theme.py:196`

**R-07-05** 复制纯文本经 `services.plain_text.to_plain_text` 去标记；该转换**只作用于复制内容，不改原文**；取回文本走桥 `request_text`。
- 依据：`plain_text.py:34-75`（`to_plain_text`）；`main.pyw:251-263`（`copy_as_plain_text`）

**R-07-06** 导出/复制取回文本走桥 `request_text`（异步），回调 `None` 视为失败并提示，禁止同步持有文本写导出。
- 依据：排查报告 R1/R7；`actions.py:78-100`（`export_html`）、`main.pyw:251-263`（`copy_as_plain_text`）

## 禁止事项
- 禁止导出 `slug` 与阅读层不一致（R-07-02）。
- 禁止在 `export.py`/`app.css` 写死色值（R-04；见 04 R-04-01/02）。
- 禁止导出 hljs 明度错配（R-07-04）。
- 禁止复制改动原文（R-07-05）。
- 禁止同步持有文本写导出（R-07-06）。
- 禁止在 `plain_text.py` 之外另写 Markdown→纯文本转换（R-07-03）。

## 与其它规格的依赖
- 依赖 **04-主题与样式系统**（`preview_css`/`hljs` 同源；代码高亮唯一实现为 highlight.js，导出内联 `hljs-light`/`hljs-dark` CSS）。
- 依赖 **02-文件与标签生命周期**（`request_text` 取文契约）。
- 依赖 **05-桥协议**（`request_text` 状态机）。
