# 规格 04 · 主题与样式系统

> 类型：主规格（系统当前必须遵守的规则）｜建立：2026-10-26｜更新：2026-10-26（审校：新增 R-04-05 禁止写死色值 / R-04-02 三处同步）｜来源：排查报告《功能地图与风险点排查.md》

## 适用范围
4 套主题定义、`css_vars()` 颜色唯一数据源、前端 `setTheme`、HTML 导出样式、字号。覆盖 `src/core/theme.py`、`src/assets/app.js`、`src/ui/main_window.py` 主题菜单。

## 必须遵守的规则

**R-04-01** `theme.css_vars()` 是页面颜色**唯一数据源**；前端 `setTheme` 逐条 `setProperty` 注入。新增或改主题须**同步改 `css_vars` 与 `THEMES`**，禁止在别处另定义颜色。
- 依据：排查报告 R5；`theme.py`；`app.js`

**R-04-02** 主题为固定 4 集合（`paper`/`midnight`/`forest`/`pure`），切换记入配置 `theme` 字段并即时下发前后端。新增主题须同步三处：`THEMES`（`theme.py`）、`css_vars`（`theme.py`）、导出 hljs 明度映射（`theme.py` / `export.py`），缺一不可。
- 依据：`theme.py`；`main.pyw`；`export.py`

**R-04-03** `__hljs` 暗/亮：`midnight → dark`，其余 `light`；HTML 导出所选 hljs CSS（`hljs-dark`/`hljs-light`）必须与 `__hljs` 一致。
- 依据：排查报告 R5；`theme.py` 的 `css_vars()` 中 `__hljs` 赋值行；`export.py`

**R-04-04** 字号经 `setFont` 改 `--ed-size`/`--ed-font`/`--fs`；配置 `font.size`/`font.family` 为唯一口径。
- 依据：`app.js`；`main.pyw`；`config.py`

**R-04-05** 前端与导出只允许消费 `css_vars()`，禁止任何文件写死主题色值；新增色值先加 `THEMES`/`css_vars`，再消费。`app.css` 中 `:root` 的十六进制仅为 CSS 变量首帧兜底默认值，不得作为主题数据源。
代码高亮**唯一实现为 highlight.js**（前端 `highlight.min.js` + 导出内联 `hljs-light`/`hljs-dark` CSS）；**禁止引入第二套高亮器（如 Pygments）**——双轨并行会出现两套配色，且导出与阅读层必然不一致（2026-10-26 已删除 v2 遗留的 `pygments_style()` 死函数）。
- 依据：`theme.py`；`app.js`；`export.py`；`app.css`（兜底默认）

**R-04-06【页面骨架布局】**（2026-11-02 建立）
- `body` 必须为 `display:flex; flex-direction:column`，`#stack` 用 `flex:1; min-height:0`。
  **禁止**给 `#stack` 设 `height:100%` —— 与 `#tabbar`（36px）相加会超过视口，
  `body{overflow:hidden}` 会把超出的部分裁掉，**标签栏因此消失**（实测 136% 高度）。
- 侧栏（`#toc`）与内容区必须同属一个 flex 行容器，不得用 absolute 叠层（R-03-02 的 hidden 互斥语义不变）。
- 依据：`app.css` body / #stack / #toc；实测 tabbarH=36 + stackH=827 = bodyH=863。

**R-04-07【系统主题跟随 + 外壳 token】**（2026-11-02 建立）
- 新增 `layout.ui_theme ∈ {system, light, dark}`（默认 `system`）：`system` 时按 Windows 应用亮/暗映射到 light/dark 外壳；手动锁定则不跟随系统。
- 外壳颜色/阴影/圆角/字号以 `css_vars()` 追加的**外壳 token**（`--ui-bg/--ui-surface/--ui-border/--ui-shadow/--ui-titlebar-bg/--ui-text/--ui-muted` 等）为唯一来源；禁止在 `app.css` 写死外壳色值（延续 R-04-05）。
- 具体取值见 `specs/00`「应用外壳视觉法」数值表；Win11 条件启用 Mica/圆角、Win10 降级见 R-01-07。
- 依据：`theme.py`、`app.css` 外壳选择器、`specs/00` 外壳数值表

## 禁止事项
- 禁止在编辑器/阅读层硬编码颜色（须走 CSS 变量）。
- 禁止导出 hljs 明度与 `__hljs` 不一致。
- 禁止在 4 主题集合外新增未登记主题（新增须先扩 `THEMES`+`css_vars`）。

## 与其它规格的依赖
- 依赖 **07-导出与复制纯文本**（`preview_css`/`hljs` 同源；代码高亮唯一实现为 highlight.js，导出内联 `hljs-light`/`hljs-dark` CSS）。
- 依赖 **05-桥协议**（`set_theme`/`set_font` 下行）。
- 被 **02-配置与持久化** 依赖（`theme`/`font` 字段持久化）。
