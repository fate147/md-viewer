# 规格 03 · 编辑⇄阅读双态与排版

> 类型：主规格（系统当前必须遵守的规则）｜建立：2026-10-26｜更新：2026-10-26（R-03-03 渲染归属修正 + 补 R-03-08 术语统一 + 审校：同源方式/阈值）｜来源：排查报告《功能地图与风险点排查.md》

## 适用范围
F2 双态切换、编辑层 CodeMirror 6、阅读层 marked+hljs 渲染、卷/章结构识别、滚动锚点对齐、排版模式（auto/book/doc）。覆盖 `src/assets/app.js`、`editor.js`、`reader.js`、`app.html`。

## 必须遵守的规则

**R-03-01** 全应用只有一个 `EditorView`，多标签靠切换 `EditorState`（`view.setState`）；撤销/重做历史随状态天然隔离，禁止为每个标签新建 `EditorView`。
- 依据：`editor.js:116-129`、`app.js:130`、`:263-281`

**R-03-02** F2 为同页显隐互换（用 `hidden` 属性），编辑层与阅读层常驻同一 DOM，无导航、不新建页面。
- 依据：`app.js:63-105`、`:294`；`editor.js:102`；`app.html:11-15`

**R-03-03【阅读层渲染归属】** `renderedRev` 的语义是「**阅读区 DOM 当前归属**」，形如 `{ id, rev }` 的**单值**，不是 per-tab 的 `Map`——因为阅读区全局只有一份 DOM（`app.js:14` 单个 `#reader`）。仅当 `renderedRev.id === activeId && renderedRev.rev === d.rev` 时，才允许跳过重渲染、只恢复 `readerScroll`；**切换标签必然改变 DOM 归属，必须重渲染**（`switchActive` 内无条件调 `renderActiveReader()`），不适用跳过规则。禁止用「该标签曾经渲染过 rev」推断「阅读区现在显示的是它」——渲染 B/C 会覆盖 A 的 DOM，而 A 的旧记账不会自动失效。
- 依据：`app.js:14,30,73-105,128,219,263-281`（`renderedRev` 单值归属比对）；排查记录：多标签切换内容错乱（2026-10-26）
- 违反后果：切到非最后打开的标签时阅读区仍显示上一个标签的内容，且 F2 往返也无法恢复（`rev` 未变会走跳过分支）。
- **迁移状态**：已同步（2026-10-26）：`renderedRev` 改为 `{id, rev}` 单值，抽 `renderActiveReader()`/`readerShows()`，落地于 `app.js:30,73-100,102-119,142,233-236,295-299`

**R-03-04** 卷/章结构识别（`STRUCT_RES` / `structKindOf`）为纯文本小说排版分层：编辑层行装饰与阅读层提升规则**必须同源**——保证方式为「引用同一实现」：编辑层 `editor.js:67` 直接调用阅读层 `window.MDV.structKindOf`（`reader.js:39-41`），后者基于 `MDV.STRUCT_RES`（`reader.js:24-27`）与 `STRUCT_MAX_LEN`（`reader.js:28`），规则只有一份；禁止编辑层另写正则。
- 依据：排查报告 R9 同源原则；`editor.js:59-77,67`、`reader.js:24-36,39-41,45-81`

**R-03-05** 排版模式 `auto|book|doc`：由 Python 配置下发，JS 只渲染不决策（auto 时按 `detectDocMode`：代码围栏数+表格数 ≥ 2 判为文档模式，阈值见 `reader.js:106`）。
- 依据：`app.js:145-157`、`reader.js:89-107`（阈值在 `:106`）；`main.pyw:88-89`、`:275-282`

**R-03-06** 滚动锚点对齐：编辑→阅读（`anchorReaderFromEditor`）与阅读→编辑（`anchorLineFromReader`）的锚点算法必须一致，保证 F2 切换位置对应。
- 依据：`reader.js:194-251`

**R-03-07** 配色全部走 CSS 变量；主题/字号切换只改 CSS 变量（`--bg/--fg/...`），不重建视图、不在编辑器/阅读层硬编码颜色。
- 依据：排查报告 R5；`editor.js:30-55`、`:159-164`；`app.js:166-172`

**R-03-08【术语统一】** 全系统术语统一为“编辑 ↔ 阅读”，禁止再用“预览”（欢迎页、帮助文案、菜单同步）。
- 依据：排查报告 D7；`welcome.py:15,22`

## 禁止事项
- 禁止为标签切换或 F2 重建 `EditorView`。
- 禁止在同一标签、同一 `rev` 时全量重渲染阅读层；但**切换标签必须重渲染**（R-03-03）。
- 禁止编辑/阅读层配色硬编码（须走 CSS 变量，见 04）。
- 禁止卷章识别规则在编辑层与阅读层分叉。
- 禁止术语混用“预览”（须用“阅读”，见 R-03-08）。
