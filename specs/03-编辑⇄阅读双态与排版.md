# 规格 03 · 编辑⇄阅读双态与排版

> 类型：主规格（系统当前必须遵守的规则）｜建立：2026-10-26｜更新：2026-11-06（补 R-03-15 目录开合保锚；R-03-02 0ms 豁免）｜前一版：2026-11-01（补 R-03-09~13 长文档阅读：分块渲染/大纲索引/章间跳转/中文排版口径/结构识别词表扩充）｜来源：排查报告《功能地图与风险点排查.md》

## 适用范围
F2 双态切换、编辑层 CodeMirror 6、阅读层 marked+hljs 渲染、卷/章结构识别、滚动锚点对齐、排版模式（auto/book/doc）。覆盖 `src/assets/app.js`、`editor.js`、`reader.js`、`app.html`。

## 必须遵守的规则

**R-03-01** 全应用只有一个 `EditorView`，多标签靠切换 `EditorState`（`view.setState`）；撤销/重做历史随状态天然隔离，禁止为每个标签新建 `EditorView`。
- 依据：`editor.js`、`app.js`

**R-03-02** F2 为同页显隐互换（用 `hidden` 属性），编辑层与阅读层常驻同一 DOM，无导航、不新建页面。**显隐不做过渡动画，保持 0ms**——两层是同一文字的两种表示，禁止交叉淡化/叠化；`#reader` 与 `#editor-host` 不得加 `transition`/`animation`（2026-11-06 增补）。
- 依据：`app.js`；`editor.js`；`app.html`

**R-03-03【阅读层渲染归属】** `renderedRev` 的语义是「**阅读区 DOM 当前归属**」，形如 `{ id, rev }` 的**单值**，不是 per-tab 的 `Map`——因为阅读区全局只有一份 DOM（`app.js` 单个 `#reader`）。仅当 `renderedRev.id === activeId && renderedRev.rev === d.rev` 时，才允许跳过重渲染、只恢复 `readerScroll`；**切换标签必然改变 DOM 归属，必须重渲染**（`switchActive` 内无条件调 `renderActiveReader()`），不适用跳过规则。禁止用「该标签曾经渲染过 rev」推断「阅读区现在显示的是它」——渲染 B/C 会覆盖 A 的 DOM，而 A 的旧记账不会自动失效。
- 依据：`app.js`（`renderedRev` 单值归属比对）；排查记录：多标签切换内容错乱（2026-10-26）
- 违反后果：切到非最后打开的标签时阅读区仍显示上一个标签的内容，且 F2 往返也无法恢复（`rev` 未变会走跳过分支）。
- **迁移状态**：已同步（2026-10-26）：`renderedRev` 改为 `{id, rev}` 单值，抽 `renderActiveReader()`/`readerShows()`，落地于 `app.js`

**R-03-04** 卷/章结构识别（`STRUCT_RES` / `structKindOf`）为纯文本小说排版分层：编辑层行装饰与阅读层提升规则**必须同源**——保证方式为「引用同一实现」：编辑层 `editor.js` 直接调用阅读层 `window.MDV.structKindOf`（`reader.js`），后者基于 `MDV.STRUCT_RES`（`reader.js`）与 `STRUCT_MAX_LEN`（`reader.js`），规则只有一份；禁止编辑层另写正则。
- 依据：排查报告 R9 同源原则；`editor.js`、`reader.js`

**R-03-05** 排版模式 `auto|book|doc`：由 Python 配置下发，JS 只渲染不决策。auto 时按 `detectDocMode` 判别（2026-11-05 升级）：
- 有代码围栏或表格（≥1）且中文小说卷/章行 < 3 → 文档模式；
- 无代码/表格时，标题 ≥ 3 且（列表 ≥ 5 或行内代码 ≥ 4 或链接 ≥ 3）→ 文档模式；
- 中文小说结构（第X卷/部/章/节/回）优先判为书卷，避免误伤。
- 依据：`app.js`、`reader.js`（阈值在 ）；`main.pyw`

**R-03-06** 滚动锚点对齐：编辑→阅读（`anchorReaderFromEditor`）与阅读→编辑（`anchorLineFromReader`）的锚点算法必须一致，保证 F2 切换位置对应。
- 依据：`reader.js`

**R-03-07** 配色全部走 CSS 变量；主题/字号切换只改 CSS 变量（`--bg/--fg/...`），不重建视图、不在编辑器/阅读层硬编码颜色。
- 依据：排查报告 R5；`editor.js`；`app.js`

**R-03-08【术语统一】** 全系统术语统一为“编辑 ↔ 阅读”，禁止再用“预览”（欢迎页、帮助文案、菜单同步）。
- 依据：排查报告 D7；`welcome.py`

**R-03-09【分块渲染阈值与不变量】**（2026-11-01 建立，v3.1 长文档阅读）
- **路径选择**：以字符数（JS `doc.length`，UTF-16 码元）为准，`CHUNK_THRESHOLD = 1_000_000`，常量置于 `reader.js` 顶部且为唯一源。
  - ≤ 阈值 → 现行全量路径（`marked.parse` → `innerHTML`）；
  - > 阈值 → 分块路径。
- **基线例外（实测口径，勿改）**：2.3MB 中文小说约 **800,000 字符**（UTF-8 纯中文 3 字节/字），**必须留在全量路径**，以保持 v3.0 已验证的 1.23s 行为不变。分块路径是新增能力，不是替换既有能力。
- **分块路径**：`marked.lexer(text)` → `blockify()` 归组 → 块表 `{tokens, estHeight, rendered, el}` → `renderWindow(视口 ±2 屏)`；滚动增量渲染，不得一次性注入全文 DOM。
- **不变量（全部满足，缺一即视为违反本规格）**：
  ① 六项后处理（标题 `id`/`slug` 去重、`data-kind`、相对图片改绝对 URL、代码块增强、hljs 高亮、表格外层包裹 `.table-wrap`）必须对**每一块**生效，且同一块不得重复执行；
  ② 分块**不得卸载已渲染块**——离开视口只停止继续渲染，已渲染内容保留。以保证 Ctrl+A、选区、导出、滚动比例语义与全量模式一致；
  ③ **标题与其紧随的首个非 `space` token 必须同属一个块组**——`app.css` 用相邻兄弟选择器 `h1 + p` 取消标题后首段缩进，跨块插入占位节点会使该规则静默失效；
  ④ `anchorReaderFromEditor` / `anchorLineFromReader` / `readerScrollRatio` 在分块模式下必须与全量模式返回一致的语义位置（改用「块索引 + 块内偏移 + 高度前缀和」，禁止用未渲染块的 `offsetTop`）；
  ⑤ 单块超过 **4000 字符**须按段落边界再切分，防止超长段落退化为全量。
- **锚点调用契约不变**：`app.js` 的 `MDV.renderReader(text, baseDir)` 签名与 `renderedRev` 记账语义**不得改动**，分块只换 `renderReader` 内部实现（与 R-03-03 对齐）。
- **回滚开关**：`CHUNK_THRESHOLD = Infinity` 即全部走全量路径，代码不产生双份实现分叉。
- 依据：`reader.js`（唯一全量瓶颈）（`HL_CAP`）（后处理）、`app.css`；`marked v12.0.2` 实测导出 `lexer`/`parser` 且 `parser(tokenSubset)` 可用；**2026-11-01 实测**：2.3MB UTF-8 中文 ≈ 80 万字符（原拟 200K 阈值会误把基线推进分块路径，已改为 1M）
- **迁移状态**：**已同步（2026-11-01，阶段 3）**——`reader.js` 落地 `renderChunked/renderFull` 双路径、`blockify`、`renderWindow`、`measureRendered`、`_recalibrate`。实测 117 万字符（4822 块）：首屏 60 块，滚动增量渲染，3 万 / 60 万 / 末尾三档定位全部正确。
- **实施补充（2026-11-01 实测，均为不变量落地必需的机制）**：
  ① **占位是硬前提**：未渲染块必须在 DOM 中保留占位元素撑高度，否则文档总高只等于已渲染块之和，滚动条到不了后文（实测 4822 块只渲染 11 块、maxScroll 仅 3293px）。
  ② **渲染预算**：单帧最多渲染 `RENDER_BUDGET=60` 块，防止滚动时一次性渲染导致主线程阻塞（实测无预算时 rAF 超时 30s）。
  ③ **高度一律用「块自报值」**：`rebuildPrefix` 只读 `blk._h`（渲染后下一帧由 `measureRendered` 统一回填），**不得在同一帧内调 `getBoundingClientRect`**——同帧多次测量会拿到过期值，是定位错乱主因。
  ④ **分块大纲必须从块 raw 建**：分块后 DOM 只有占位，未渲染标题不存在，`buildOutline` 若仍查 DOM 会得到空索引。

**R-03-10【大纲索引唯一数据源】**（2026-11-01 建立）
- 大纲索引由 `MDV.buildOutline()` 单一实现产出，结构 `[{level, kind, text, id, blockIndex, offsetTop, chars}]`；`kind` 取值为 `volume|chapter|heading`，`chars` 为本章字符数。
- **归属规则**：`chapter` 归属其前最近的 `volume`；首个 `volume` 之前的 `chapter` 归入伪卷「序」；全文无卷无章时退化为按 `h1–h6` 建树。
- **唯一消费者四处**——目录侧栏、位置显示、章间跳转、`renderedRev` 失效后的重建时机——只允许读该索引，**禁止各自重算标题集合**（同源原则，类比 R-03-04）。
- 依据：`reader.js`（现有 heading 遍历与 slug 去重）、`reader.js`（卷章提升）、`app.js`
- **标签切换必须作废大纲（2026-11-01，R-03-10 补充）**：`MDV.outline` 是模块级变量，
  `renderReader` 必须显式重置为 `[]` 并置 `_outlineMeasured = false`。
  修前遗漏：切到另一标签后目录仍显示**上一个标签**的卷章（实测 A 有 12 章、切到 2 章的 B，目录仍是 A 的 12 条）。
  依据：`reader.js` renderReader；`specs/02`「大纲索引随标签作废」。

- **目录可滚动 + 行高常量（2026-11-02，2026-11-05 修订）**：
  `TOC_ROW_H` 必须等于 `.toc-item` 的实测高度（当前 **36px**；`.toc-item` 已固定 `height:36px` + `box-sizing:border-box`，原写 24 导致占位与真实行高不符、
  滚动位置漂移）。**用户手动滚目录时，`syncActive` 不得把目录窗口强行拉回当前章** ——
  否则目录根本滚不动（实测：用户滚动后立刻被拉回）。实现为 `_userScrolledAt` 时间戳 + `USER_GRACE_MS=1200` 宽限窗。

- **目录窗口化（2026-11-01，计划 2.3）**：条目 > `TOC_MAX_ITEMS=200` 时**只渲染可见窗**
  （上下各预渲染 20 行 + 等高占位撑滚动范围），**不是整表放弃**。
  修前实现为「>400 项则不显示目录」，导致 400–2000 项的长篇完全没有目录。
  实测：300 章文档 DOM 行数恒为 56，滚动后窗口平移，总高守恒。

- **高亮按视口（2026-11-01，计划 3.5）**：`HL_CAP` 语义为「首屏同步高亮的块数上限」，
  **不再表示「全文只高亮前 N 块」**；剩余块在滚动进入视口时补高亮（`data-hl` 去重，
  单次上限 `HL_IDLE_LIMIT=200`）。修前第 501 块起永远是纯文本。

- **结构识别必须兼容「章行紧贴正文」（2026-11-01，R-03-13 修正）**：
  旧规则要求卷/章行**前后都是空行**才提升为标题。但真实中文小说普遍是
  `第一章：诡异现场` 紧跟全角缩进的正文、中间没有空行——
  实测《鬼探实录》250 个章行全部不满足该条件，**目录里 0 个章**（只有 6 个卷）。
  修正为：**prevBlank 必须成立**（防止正文段落中的同名单句被误伤），
  **nextBlank 放宽**为「下一行不是另一个卷/章行」。
  实测：256 条（6 卷 + 250 章），字数归属正常（卷 26.7 万 / 章 3.1k）。

- **渲染同步阶段禁止读布局（2026-11-01，第二次踩到）**：
  `buildOutline` 不得读 `h.offsetTop` —— 刚 `innerHTML` 换完，DOM 是脏的，
  这一次读触发全量布局，实测 786K 字符 **450ms**。坐标统一由 `remeasureOutline()`
  在 rAF 里回填。与 `anchorReaderFromEditor` 同一类问题（R-03-09 不变量④）。

- **structKind 首字符预筛（2026-11-01）**：全文扫描时 99% 的行不可能是卷/章标题，
  先按首字符（第/楔/序/引/尾/终/后/番/附/结）挡掉，避免每行跑 6 条正则。

- **性能约束（2026-11-01 回归测试新增，不得回退）**：
  ① 大纲构建**禁止**对每个标题调用 `createRange().toString()` 或等价的 O(n²) 定位（实测 3955 标题 9.9 秒）；字数归属必须用「一次扫描原文偏移」（`buildRawOffsetsFor`），全量与分块两条路径共用同一算法。
  ② 批量读取 `offsetTop` 时**禁止**在循环条件里逐个读（每次都是一次强制布局）；必须先取快照数组。
  ③ 目录条目超过 `TOC_MAX_ITEMS=200` 时按「目录窗口化」只渲染可见窗（见 R-03-10「目录窗口化」条），不得整表放弃、不得显示「条目过多」；旧「400 不建 DOM、提示条目过多」条款已于 2026-11-02 废止（与本文件 R-03-10「目录窗口化」及 `toc.js` 实现对齐）。
  ④ 渲染后的坐标重测必须放在 `requestAnimationFrame`，不得在布局脏状态下同步读 `offsetTop`。

- **迁移状态**：**已同步（2026-11-01，阶段 2）**——落地于 `reader.js` 的 `buildOutline()` / `outlineTree()` / `currentSection()` / `ensureOutline()` / `remeasureOutline()`，消费方为新增 `toc.js`（目录侧栏）与 `main.pyw._on_section`（状态栏）。
- **实测补充 2（2026-11-01）**：`MDV.outline` 为模块级变量，`renderReader` 必须显式作废（见上方「标签切换必须作废大纲」），否则切标签后目录串档。
- **实测补充（2026-11-01）**：`buildOutline()` 在渲染同步阶段调用时，布局尚未完成，`offsetTop` 全为 0，会导致定位全部落到末章。**必须经 `ensureOutline()` 惰性重测 / `remeasureOutline()` 在布局完成后回填**，此为索引可用性的前提条件。

- **章/卷上报口径（2026-11-02）**：`currentSection()` 的 `volume/chapter` 只统计 `kind=volume/chapter` 的条目；`kind=heading`（含纯文本小说提升出来的书名 h1、文档模式 h1–h6）**不得计为「章」**，与分块路径口径一致——修前全量路径把书名 h1 当成「章」显示在状态栏。

**R-03-11【章间跳转语义】**（2026-11-01 建立）
- 章间跳转 = 目标章落的块顶部进入视口（沿用既有 `offsetTop - 24` 偏移口径，见 `reader.js`），**不是翻屏、不是翻页**。
- 目标块处于未渲染区时必须先渲染该块再定位，**禁止跳到估算高度或占位节点上**（与 R-03-09 不变量④协作）。
- `Ctrl+←` / `Ctrl+→` 在阅读态执行上一章/下一章；编辑态不绑定（避免与 CodeMirror 光标移动冲突）。
- 依据：`reader.js`；`app.js`（全局快捷键表）
- **迁移状态**：**已同步（2026-11-01，阶段 2）**——落地于 `MDV.jumpChapter(dir)`，快捷键挂在 `app.js` 全局 keydown 的 `Ctrl+←/→` 分支（仅 `state.mode === "reader"` 生效）。实测：前进/后退/跨卷三档位置均与预期一致。

**R-03-12【中文排版规则口径】**（2026-11-01 建立；拍板 B：不改写字符）
- 阅读层中文排版的取值以 **`specs/00` 中文排版数值表**为唯一源，禁止在 `app.css` 与 `reader.js` 各写一份规则。
- **实现层次优先级**：CSS 原生优先（`line-break` / `text-spacing-trim` / `text-autospace`）；CSS 无法表达且不改变原文语义时，允许渲染后 DOM 处理；**禁止改写源文本**——`state.docs` 缓冲与 `__getTextChunk` 取到的文本必须与文件内容逐字一致。
- 具体禁止：不得把 `--` 替换为 `——`、不得把 `...` 替换为 `……`、不得插入零宽字符或任何不可见字符来伪造间距（保证「复制纯文本」与屏幕一致）。
- 浏览器不支持某属性时**必须静默降级**，禁止抛错、禁止用 JS 模拟替代。
- 依据：`app.css`（`.md-body` 排版细则）（缩进排除）；`reader.js`；`services/plain_text.py`
- **迁移状态**：**已同步（2026-11-01，阶段 1）**——`app.css` 落地三项 CSS 原生属性（`text-autospace: normal` / `line-break: strict` / `text-spacing-trim: space-first`），并补「代码块/表格/列表/hr 后段落不缩进」排除规则；**零 JS 介入、源文本零改写**。WebView2 支持度已实测：三属性均被识别，`hanging-punctuation` 不支持（未使用）。

**R-03-13【结构识别词表扩充】**（2026-11-01 建立）
- 现有 `STRUCT_RES` 只覆盖「第X卷/部」「第X章/节/回」，**实测「楔子 / 序章 / 序幕 / 尾声 / 终章 / 番外 / 后记」均识别为 null**（`reader.js`），导致这类中文常见章节在阅读层无层级、在目录侧栏中缺失。
- 扩充后 `STRUCT_RES` 必须仍为**单一份实现**（R-03-04 同源约束不变），编辑层装饰与阅读层提升同时生效。
- 新词表条目只认「整行且长度 ≤ `STRUCT_MAX_LEN`」的独立行，不得误伤正文中出现的同名词（沿用现行护栏）。
- 新增条目的 `kind` 归类（**2026-11-01 定稿**）：**开篇类与收束类一律归 `chapter`**，不归 `volume`。理由：它们是「章节」而非「卷」，若归 `volume` 会顶替掉其所在真实的卷（实测「第二卷 暗河」的子章被整体挂到「楔子」名下）。首个 `volume` 之前出现时，由 R-03-10 的伪卷「序」收纳。
- 依据：`reader.js`（词表）（`STRUCT_MAX_LEN`）（`structKind`）；2026-11-01 实测九个常见标题仅七个可识别
- **迁移状态**：**已同步（2026-11-01，阶段 2）**——词表扩至 6 条（新增「楔子|序章|序幕|序言|引子」与「尾声|终章|后记|番外|附录|结局」）。实测：13 个应命中标题全部命中；6 条长正文（如「楔子里他看到一个黑影」）全部未误伤。
- **连带修复**：词表扩充后必然触发 `editor.js` 既有 bug（`Decoration.set(b.finish())` 把 `RangeSet` 当可迭代对象 → `object is not iterable`），已一并修为 `return b.finish()`。该 bug 原先因首屏极少命中卷/章行而未暴露。

**R-03-14【超大书卷禁止进入编辑态】**（2026-11-02 建立）
- 触发条件：**文本长度 > `F2_EDIT_MAX_CHARS`（200_000 字符）且当前为书卷模式**。
- 行为：拒绝 `F2` 切换，保持阅读态，并在状态栏提示「文档过大，暂不支持编辑」。
  非书卷模式（文档模式）不受限。
- **依据（实测）**：776K 字符小说切到编辑态，**第二次**耗时 **636ms**（首次仅 72ms）——
  CodeMirror 首次真正布局全部 10690 行时的固有开销，非本项目逻辑缺陷。
  锚点（2ms）与 `setState`（1ms）均已排除。
- 该限制必须拦**所有进入编辑态的交互入口**（F2 / 菜单 / `Ctrl+F`·`Ctrl+H` 查找替换），任何入口都不得绕过 `setMode("editor")`；不改变数据，文档仍在阅读层完整可读。
- 依据：`app.js` `MDV.toggleMode` / 统一入口 `enterEditor()` / `runCmd("find")`；`main_window.py` 菜单项。
- **2026-11-02 补漏**：修前只有 `toggleMode` 有守卫，`runCmd("find")` 直接 `setMode("editor")` 绕过，实测 776K 小说 `Ctrl+F` 仍进入编辑态并卡顿 ~875ms。现所有入口统一经 `enterEditor()`。

**R-03-15【目录开合保锚】**（2026-11-06 建立）
- 触发条件：用户**手动**切换目录可见性（`MDV.toggleToc`，含菜单「切换目录」/`Ctrl+Shift+O`）。
- 行为：切换前记录 `MDV.currentSection()` 的 `chapterId`（无章节则 `volumeId`）；切换后在下一帧调用 `MDV.scrollToHeading` 回到同一标题。**禁止**以旧的 `scrollTop` 像素值"复位"——正文换行变化后像素值不对应原内容。
- 容错：`scrollToHeading` 内部按标题 id 实测 DOM（分块模式下先确保目标块渲染），命中 ±24px 即视为正确。
- 仅约束用户手动切换；启动期 `refreshToc` / `initTocVisible` 不触发保锚（无用户阅读锚点）。
- 动画：`#toc` 容器不做宽度/`flex-basis` 过渡；`#toc-list` 可做一次 120ms `opacity` 淡入；reduced-motion 下全静默。
- 依据：`app.js` `MDV.toggleToc` / `reader.js` `MDV.scrollToHeading` / `currentSection`；`app.css` `#toc`；`specs/00` 外壳行为增补。

## 禁止事项
- 禁止为标签切换或 F2 重建 `EditorView`。
- 禁止给 `#reader` / `#editor-host` 加 `transition` / `animation`（F2 0ms 豁免，R-03-02）。
- 禁止在同一标签、同一 `rev` 时全量重渲染阅读层；但**切换标签必须重渲染**（R-03-03）。
- 禁止编辑/阅读层配色硬编码（须走 CSS 变量，见 04）。
- 禁止卷章识别规则在编辑层与阅读层分叉。
- 禁止术语混用“预览”（须用“阅读”，见 R-03-08）。
- 禁止在分块路径卸载已渲染块，或让标题与其首段跨块（R-03-09 不变量②③）。
- 禁止在分块模式下用未渲染块的 `offsetTop` 定位（R-03-09 不变量④ / R-03-11）。
- 禁止绕过 `buildOutline` 自算标题集合（R-03-10）。
- 禁止改写源文本做排版（`--`→`——`、`...`→`……`、插入不可见字符）（R-03-12）。
