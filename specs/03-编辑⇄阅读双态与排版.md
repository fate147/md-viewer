# 规格 03 · 编辑⇄阅读双态与排版

> 类型：主规格（系统当前必须遵守的规则）｜建立：2026-10-26｜更新：2026-11-01（补 R-03-09~13 长文档阅读：分块渲染/大纲索引/章间跳转/中文排版口径/结构识别词表扩充）｜前一版：2026-10-26（R-03-03 + R-03-08）｜来源：排查报告《功能地图与风险点排查.md》

## 适用范围
F2 双态切换、编辑层 CodeMirror 6、阅读层 marked+hljs 渲染、卷/章结构识别、滚动锚点对齐、排版模式（auto/book/doc）。覆盖 `src/assets/app.js`、`editor.js`、`reader.js`、`app.html`。

## 必须遵守的规则

**R-03-01** 全应用只有一个 `EditorView`，多标签靠切换 `EditorState`（`view.setState`）；撤销/重做历史随状态天然隔离，禁止为每个标签新建 `EditorView`。
- 依据：`editor.js:116-129`、`app.js:130`、`:263-281`

**R-03-02** F2 为同页显隐互换（用 `hidden` 属性），编辑层与阅读层常驻同一 DOM，无导航、不新建页面。
- 依据：`app.js:63-105`、`:294`；`editor.js:102`；`app.html:11-15`

**R-03-03【阅读层渲染归属】** `renderedRev` 的语义是「**阅读区 DOM 当前归属**」，形如 `{ id, rev }` 的**单值**，不是 per-tab 的 `Map`——因为阅读区全局只有一份 DOM（`app.js:14` 单个 `#reader`）。仅当 `renderedRev.id === activeId && renderedRev.rev === d.rev` 时，才允许跳过重渲染、只恢复 `readerScroll`；**切换标签必然改变 DOM 归属，必须重渲染**（`switchActive` 内无条件调 `renderActiveReader()`），不适用跳过规则。禁止用「该标签曾经渲染过 rev」推断「阅读区现在显示的是它」——渲染 B/C 会覆盖 A 的 DOM，而 A 的旧记账不会自动失效。
- 依据：`app.js:14,30,73-105,128,219,263-281`（`renderedRev` 单值归属比对）；排查记录：多标签切换内容错乱（2026-10-26）
- 违反后果：切到非最后打开的标签时阅读区仍显示上一个标签的内容，且 F2 往返也无法恢复（`rev` 未变会走跳过分支）。
- **迁移状态**：已同步（2026-10-26）：`renderedRev` 改为 `{id, rev}` 单值，抽 `renderActiveReader()`/`readerShows()`，落地于 `app.js:30,73-100,102-119,142,233-236,295-299`

**R-03-04** 卷/章结构识别（`STRUCT_RES` / `structKindOf`）为纯文本小说排版分层：编辑层行装饰与阅读层提升规则**必须同源**——保证方式为「引用同一实现」：编辑层 `editor.js:67` 直接调用阅读层 `window.MDV.structKindOf`（`reader.js:39-41`），后者基于 `MDV.STRUCT_RES`（`reader.js:24-27`）与 `STRUCT_MAX_LEN`（`reader.js:28`），规则只有一份；禁止编辑层另写正则。
- 依据：排查报告 R9 同源原则；`editor.js:59-77,67`、`reader.js:24-36,39-41,45-81`

**R-03-05** 排版模式 `auto|book|doc`：由 Python 配置下发，JS 只渲染不决策（auto 时按 `detectDocMode`：代码围栏数+表格数 ≥ 2 判为文档模式，阈值见 `reader.js:106`）。
- 依据：`app.js:145-157`、`reader.js:89-107`（阈值在 `:106`）；`main.pyw:88-89`、`:275-282`

**R-03-06** 滚动锚点对齐：编辑→阅读（`anchorReaderFromEditor`）与阅读→编辑（`anchorLineFromReader`）的锚点算法必须一致，保证 F2 切换位置对应。
- 依据：`reader.js:194-251`

**R-03-07** 配色全部走 CSS 变量；主题/字号切换只改 CSS 变量（`--bg/--fg/...`），不重建视图、不在编辑器/阅读层硬编码颜色。
- 依据：排查报告 R5；`editor.js:30-55`、`:159-164`；`app.js:166-172`

**R-03-08【术语统一】** 全系统术语统一为“编辑 ↔ 阅读”，禁止再用“预览”（欢迎页、帮助文案、菜单同步）。
- 依据：排查报告 D7；`welcome.py:15,22`

**R-03-09【分块渲染阈值与不变量】**（2026-11-01 建立，v3.1 长文档阅读）
- **路径选择**：以字符数（JS `doc.length`，UTF-16 码元）为准，`CHUNK_THRESHOLD = 1_000_000`，常量置于 `reader.js` 顶部且为唯一源。
  - ≤ 阈值 → 现行全量路径（`marked.parse` → `innerHTML`）；
  - > 阈值 → 分块路径。
- **基线例外（实测口径，勿改）**：2.3MB 中文小说约 **800,000 字符**（UTF-8 纯中文 3 字节/字），**必须留在全量路径**，以保持 v3.0 已验证的 1.23s 行为不变。分块路径是新增能力，不是替换既有能力。
- **分块路径**：`marked.lexer(text)` → `blockify()` 归组 → 块表 `{tokens, estHeight, rendered, el}` → `renderWindow(视口 ±2 屏)`；滚动增量渲染，不得一次性注入全文 DOM。
- **不变量（全部满足，缺一即视为违反本规格）**：
  ① 五项后处理（标题 `id`/`slug` 去重、`data-kind`、相对图片改绝对 URL、代码块增强、hljs 高亮）必须对**每一块**生效，且同一块不得重复执行；
  ② 分块**不得卸载已渲染块**——离开视口只停止继续渲染，已渲染内容保留。以保证 Ctrl+A、选区、导出、滚动比例语义与全量模式一致；
  ③ **标题与其紧随的首个非 `space` token 必须同属一个块组**——`app.css:193-194` 用相邻兄弟选择器 `h1 + p` 取消标题后首段缩进，跨块插入占位节点会使该规则静默失效；
  ④ `anchorReaderFromEditor` / `anchorLineFromReader` / `readerScrollRatio` 在分块模式下必须与全量模式返回一致的语义位置（改用「块索引 + 块内偏移 + 高度前缀和」，禁止用未渲染块的 `offsetTop`）；
  ⑤ 单块超过 **4000 字符**须按段落边界再切分，防止超长段落退化为全量。
- **锚点调用契约不变**：`app.js:109-119` 的 `MDV.renderReader(text, baseDir)` 签名与 `renderedRev` 记账语义**不得改动**，分块只换 `renderReader` 内部实现（与 R-03-03 对齐）。
- **回滚开关**：`CHUNK_THRESHOLD = Infinity` 即全部走全量路径，代码不产生双份实现分叉。
- 依据：`reader.js:111`（唯一全量瓶颈）、`:16-17`（`HL_CAP`）、`:113-180`（后处理）、`app.css:189,193-194`；`marked v12.0.2` 实测导出 `lexer`/`parser` 且 `parser(tokenSubset)` 可用；**2026-11-01 实测**：2.3MB UTF-8 中文 ≈ 80 万字符（原拟 200K 阈值会误把基线推进分块路径，已改为 1M）
- **迁移状态**：未同步（阶段 3 实施）

**R-03-10【大纲索引唯一数据源】**（2026-11-01 建立）
- 大纲索引由 `MDV.buildOutline()` 单一实现产出，结构 `[{level, kind, text, id, blockIndex, offsetTop, chars}]`；`kind` 取值为 `volume|chapter|heading`，`chars` 为本章字符数。
- **归属规则**：`chapter` 归属其前最近的 `volume`；首个 `volume` 之前的 `chapter` 归入伪卷「序」；全文无卷无章时退化为按 `h1–h6` 建树。
- **唯一消费者四处**——目录侧栏、位置显示、章间跳转、`renderedRev` 失效后的重建时机——只允许读该索引，**禁止各自重算标题集合**（同源原则，类比 R-03-04）。
- 依据：`reader.js:113-122`（现有 heading 遍历与 slug 去重）、`reader.js:45-81`（卷章提升）、`app.js:105-119`
- **迁移状态**：未同步（阶段 2 实施）

**R-03-11【章间跳转语义】**（2026-11-01 建立）
- 章间跳转 = 目标章落的块顶部进入视口（沿用既有 `offsetTop - 24` 偏移口径，见 `reader.js:222-228`），**不是翻屏、不是翻页**。
- 目标块处于未渲染区时必须先渲染该块再定位，**禁止跳到估算高度或占位节点上**（与 R-03-09 不变量④协作）。
- `Ctrl+←` / `Ctrl+→` 在阅读态执行上一章/下一章；编辑态不绑定（避免与 CodeMirror 光标移动冲突）。
- 依据：`reader.js:222-228`；`app.js:313-325`（全局快捷键表）

**R-03-12【中文排版规则口径】**（2026-11-01 建立；拍板 B：不改写字符）
- 阅读层中文排版的取值以 **`specs/00` 中文排版数值表**为唯一源，禁止在 `app.css` 与 `reader.js` 各写一份规则。
- **实现层次优先级**：CSS 原生优先（`line-break` / `text-spacing-trim` / `text-autospace`）；CSS 无法表达且不改变原文语义时，允许渲染后 DOM 处理；**禁止改写源文本**——`state.docs` 缓冲与 `__getTextChunk` 取到的文本必须与文件内容逐字一致。
- 具体禁止：不得把 `--` 替换为 `——`、不得把 `...` 替换为 `……`、不得插入零宽字符或任何不可见字符来伪造间距（保证「复制纯文本」与屏幕一致）。
- 浏览器不支持某属性时**必须静默降级**，禁止抛错、禁止用 JS 模拟替代。
- 依据：`app.css:117-129`（`.md-body` 现有 `text-autospace`）、`:189-194`（缩进规则）；`reader.js:109-141`；`services/plain_text.py`

**R-03-13【结构识别词表扩充】**（2026-11-01 建立）
- 现有 `STRUCT_RES` 只覆盖「第X卷/部」「第X章/节/回」，**实测「楔子 / 序章 / 序幕 / 尾声 / 终章 / 番外 / 后记」均识别为 null**（`reader.js:24-36`），导致这类中文常见章节在阅读层无层级、在目录侧栏中缺失。
- 扩充后 `STRUCT_RES` 必须仍为**单一份实现**（R-03-04 同源约束不变），编辑层装饰与阅读层提升同时生效。
- 新词表条目只认「整行且长度 ≤ `STRUCT_MAX_LEN`」的独立行，不得误伤正文中出现的同名词（沿用现行护栏）。
- 新增条目的 `kind` 归类：`楔子/序章/序幕` → `volume`（或按序章处理，见 R-03-10 伪卷规则）；`尾声/终章/番外/后记` → `chapter`。**归属细节待实施阶段定稿并回写本条**。
- 依据：`reader.js:24-27`（词表）、`:28`（`STRUCT_MAX_LEN`）、`:30-36`（`structKind`）；2026-11-01 实测九个常见标题仅七个可识别
- **迁移状态**：未同步（并入阶段 2 实施）

## 禁止事项
- 禁止为标签切换或 F2 重建 `EditorView`。
- 禁止在同一标签、同一 `rev` 时全量重渲染阅读层；但**切换标签必须重渲染**（R-03-03）。
- 禁止编辑/阅读层配色硬编码（须走 CSS 变量，见 04）。
- 禁止卷章识别规则在编辑层与阅读层分叉。
- 禁止术语混用“预览”（须用“阅读”，见 R-03-08）。
- 禁止在分块路径卸载已渲染块，或让标题与其首段跨块（R-03-09 不变量②③）。
- 禁止在分块模式下用未渲染块的 `offsetTop` 定位（R-03-09 不变量④ / R-03-11）。
- 禁止绕过 `buildOutline` 自算标题集合（R-03-10）。
- 禁止改写源文本做排版（`--`→`——`、`...`→`……`、插入不可见字符）（R-03-12）。
