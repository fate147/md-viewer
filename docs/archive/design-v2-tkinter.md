# 设计系统：MD Viewer — Elegant Reader

## 1. 概述

**创意北极星：「纸间微光」**

一款安静、温暖、专注的 Windows 桌面 Markdown 阅读与写作工具。设计哲学是「消失的设计」：界面的存在是为了被遗忘，只留下内容本身。每一处表面、色彩与间距的选择，都服务于长文的舒适阅读。

这套设计明确拒绝传统 IDE 的美学（文件树、标签页、密集工具栏），也拒绝笔记类应用的视觉语言（块编辑器、数据库 UI、插件面板）。它追求一本装帧考究的平装书那样的材质温度——是可以捧在手里的物件，而不是需要操作的机器。

**核心特征：**
- 内容优先：编辑器占据窗口 90% 以上的面积
- 自动隐藏工具栏：界面元素只在需要时出现
- 4 套风格迥异的阅读主题：暖色、暗色、森林、极简
- 充裕的留白（32px 水平内边距，1.85 行高）
- 正文使用衬线字体，适合长时间阅读
- 平面表面 + 微分割线层级

## 2. 色彩

四套主题色板，各有独特氛围。每套主题都满足 WCAG AA 对比度（正文相对背景 ≥ 4.5:1）。

### 纸白主题：温润纸白 — "琥珀纸页"

主打的日间主题。暖色调的米白纸张，配以琥珀金点缀。

- **琥珀** (#d4a373)：强调色。用于链接、代码高亮、引用块边框、按钮悬停态、选区背景。一种带有泥土气息的温暖暗金色。
- **温润纸白** (#fdfbf7)：正文与表面背景。微带暖色的米白。
- **墨色** (#2c2c2c)：正文文字。柔和的近黑，避免纯黑在暖纸上显得生硬。
- **淡墨** (#888888)：次要文字（工具栏标签、状态栏）。刻意压暗，退居背景。
- **工具栏按钮** (#f0ece4)：按钮静止状态的表面色。比页面底色略深。

### 墨黑主题：深夜墨黑 — "翡翠之夜"

适合低光环境阅读的暗色主题。深炭灰配青绿色点缀。

- **翡翠** (#4ec9b0)：强调色。在暗背景下微微发光的冷青绿。用于链接、代码、引用块边框、悬停态。
- **深炭灰** (#1e1e1e)：主背景。非纯黑，减轻眼部疲劳。
- **柔银** (#d4d4d4)：正文文字。对比度高但并非纯白。
- **暗表面** (#252525)：工具栏表面，比主背景略亮。
- **选区蓝** (#3a3a5a)：文字选区背景，带冷蓝紫色调。

### 森林主题：森之息 — "智者之息"

源于自然的浅色主题。冷绿白配鼠尾草绿点缀。

- **鼠尾草** (#6b8f71)：强调色。沉稳、朴实的绿色。用于链接、代码、引用块边框。
- **雾白** (#f4f7f6)：正文背景。微带绿色的冷调米白。
- **森墨** (#1a2a2a)：正文文字。深绿黑。
- **苔色** (#4a6a50)：次要文字与按钮标签。
- **淡鼠尾草** (#e8f0eb)：按钮表面、柔和的背景填充。

### 纯白主题：极简纯白 — "清澈溪流"

高对比度的极简主题。纯白配经典天蓝点缀。

- **溪蓝** (#0366d6)：强调色。熟悉的 GitHub 风格蓝。用于链接、代码。
- **纯白** (#ffffff)：正文背景。
- **石色** (#333333)：正文文字。白底深灰，舒适不刺眼。
- **浅灰** (#f5f5f5)：按钮表面、柔和填充。

### 命名规则

**「单一声音」规则。** 在任何一屏中，强调色占可见面积不超过 5%。稀缺本身就是意义——它把视线引向可交互元素与语义化标记，又不与内容争抢注意力。

## 3. 字体

**正文/阅读字体：** Georgia, 'Noto Serif SC', serif
**界面字体：** 'Segoe UI', 'Microsoft YaHei', sans-serif
**代码字体：** 'Fira Code', 'Consolas', monospace

**气质：** 经典衬线字体负责阅读正文，清爽的无衬线字体负责界面元素。Georgia 带来传统书籍的温暖；Segoe UI 提供利落、现代的文字标签。这种对比传达出「这是内容」与「这是界面」的区别。

### 层级

- **标题级**（Georgia Bold, 22pt, 1.4）：Markdown 一级标题（`# `）。作为文档标题，克制使用。
- **副标题级**（Georgia Bold, 19pt, 1.4）：二级标题（`## `）。内容中的章节分隔。
- **正文**（Georgia Regular, 17pt, 1.85）：主要阅读与编辑文本。最大行长 65–75 字符（720px）。
- **界面标签**（Segoe UI Regular, 9–12pt）：工具栏按钮、状态栏、文件标签。
- **代码**（Consolas / Fira Code, 14pt）：Markdown 内容中的行内代码与代码块。

### 命名规则

**「阅读优先」规则。** 正文为 17px Georgia、1.85 行高，绝不小于 16px。这是一个用于阅读的应用，而不是用于编辑的 IDE。

## 4. 层级

界面整体为平面风格。深度通过色调分层而非阴影来传达：

- **编辑器表面**是基础层（z-index 0）。
- **工具栏**通过底部一条 1px 发丝分割线与编辑器区分，颜色比表面略深。
- **状态栏**同样通过顶部一条 1px 发丝线加以区分。
- **模态对话框**（主题选择、查找）浮动在所有内容之上，带 1px 与表面同调的边框，形成唯一的「浮层」层级。

不使用任何盒子阴影。默认平面化符合 Tkinter 原生能力，而微分割线避免界面显得毫无层次。

## 5. 组件

### 工具栏
- **形态：** 全宽水平条，平面，高 48px
- **背景：** 与编辑器背景一致（随主题变化）
- **行为：** 自动隐藏；鼠标悬停窗口顶部的 3px 触发条时显示。鼠标移开后 800ms 隐藏。
- **文件标签：** 左对齐，Segoe UI 11pt，柔和的浅色调
- **按钮：** 平面浮雕，10px 水平内边距，Segoe UI 10pt。静止时背景与工具栏一致；悬停时变为强调色。

### 编辑器（Text 组件）
- **形态：** 占满内容区，平面（无边框），32px 水平内边距
- **字体：** Georgia 17pt，自动换行
- **滚动条：** 标准 Tkinter 纵向滚动条，位于右侧
- **状态：** 支持撤销（100 级），光标为与文字同色的插入光标，选区为随主题变化的高亮色

### 状态栏
- **形态：** 全宽水平条，高 32px，平面
- **内容：** 左侧：字数统计。右侧：主题名 + 文件名。
- **字体：** Segoe UI 9pt，柔和配色

### 主题选择对话框
- **形态：** 300×200px 居中模态弹窗
- **背景：** 与当前主题表面一致
- **项目：** 4 个主题按钮，全宽，平面浮雕。悬停：强调色背景。

### 查找对话框
- **形态：** 380×100px 居中模态弹窗
- **内容：** 标签 + 文本输入框 + 查找按钮
- **行为：** 不区分大小写的查找，命中项黄色高亮（#FFEB3B），在状态栏显示命中数量

## 6. 该做的与不该做的

### 该做：
- **要**使用充裕的留白：编辑器 32px 水平内边距、1.85 行高。
- **要**让工具栏默认隐藏——内容才是主角。
- **要**提供 4 种不同的氛围选择（暖、暗、自然、极简）。
- **要**使用 Georgia 衬线字体作为正文；这是一款阅读工具。
- **要**在每套主题中维持 WCAG AA 对比度：正文相对背景 ≥ 4.5:1。
- **要**克制使用强调色（不超过可见表面的 5%）。
- **要**静默自动保存——无摩擦交互是设计原则。

### 不该做：
- **不要** IDE 式密集工具栏：没有复杂按钮组、状态面板堆叠、满屏配置项。文件树/标签页/大纲**可以有**，但必须**按需出现、默认克制**（侧栏可隐藏、标签条极简、无右键菜单堆砌）。
- **不要**使用块编辑、数据库 UI 或插件面板（反参考：笔记类应用）。
- **不要**用侧边条纹边框、渐变文字或毛玻璃效果装饰。
- **不要**添加数字章节标记（01/02/03）或全大写眉题文字。
- **不要**在浅色背景上用无法通过对比度检查的灰色文字。
- **不要**在暗色模式中使用纯黑（#000）背景；请改用深炭灰。
- **不要**让生产力功能抢占视觉：预览分屏、文件树、标签条的默认形态必须安静，聚焦时一键隐藏。

## 7. v2.0 新增组件（文件树/标签条/大纲/分屏预览）

> v2.0 定位「阅读质感 + 生产力工具」。以下组件全部遵循「按需出现、默认克制」：
> 默认布局 = 顶部极简标签条 + 单栏编辑器；文件树/大纲/预览分屏**默认收起**，通过菜单/快捷键唤出。

### 文件树侧栏（F02）
- **形态**：左侧可收起面板，宽 220px，平面，与主题背景同色（比编辑器背景略深一档）。
- **内容**：`ttk.Treeview`，只显示 `.md` 文件 + 文件夹层级；根为打开的文件夹名。
- **行为**：双击打开文件（进标签页）；右键菜单仅 3 项：打开/打开所在文件夹/刷新；Esc 或按钮收起。
- **配色**：选中行用主题强调色 10% 透明底；当前打开文件高亮强调色文字。

### 标签条（F03）
- **形态**：顶部 36px 条，平面；每个标签 = 文件名 + 关闭 ✕，未保存加 ● 前缀。
- **行为**：单文件时隐藏整条（阅读优先）；≥2 个文件时出现。中键点击关闭；拖拽排序（P2）。
- **配色**：活动标签 = 主题强调色下划线；非活动 = 淡灰文字；关闭 ✕ 悬停变强调色。

### 大纲面板（F05）
- **形态**：右侧可收起面板，宽 200px，平面；标题列表按层级缩进（H1~H6）。
- **行为**：点击跳转编辑器对应行并滚动预览；随编辑实时刷新（防抖 300ms）；仅当前文档标题。
- **配色**：层级缩进 12px/级；当前章节高亮强调色。

### 分屏预览（F01）
- **形态**：编辑/预览 1:1 分栏，中间 1px 拖拽分隔条；也可切换单栏（编辑 或 预览）。
- **行为**：拖拽调比例（记忆到配置）；同步滚动（滚动源方为编辑时按行高映射，预览回滚按百分比映射）。
- **配色**：分隔条 = 主题 divider 色；预览栏继承编辑器内边距（48px/40px）。
