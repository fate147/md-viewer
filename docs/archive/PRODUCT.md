## 用户

作家、开发者以及使用 Markdown 做笔记的人，在 Windows 桌面上阅读与编辑 Markdown 文件。他们使用这款工具进行专注的阅读和写作——深夜写作、技术文档、笔记整理。使用场景是安静、无干扰的环境，工具本身应隐入背景。

## 产品定位

MD Viewer 是一款 Windows 平台、无干扰的 Markdown 阅读与编辑工具。**v2.0 定位升级：「阅读质感 + 生产力工具」**——保留「纸间微光」的无干扰阅读体验（4 套护眼主题、消失式工具栏、衬线排版），同时补全真实 Markdown 预览、文件树、多标签页、大纲导航等生产力功能，成为日常 Markdown 工作台。

成功的标准是：用户忘记自己正在使用一个应用，把全部注意力放在内容上；需要组织文件、切换文档、快速定位时，工具又不缺席。

## 品牌个性

宁静、温暖、专注

安静而自信——像一本设计精良的纸质书，而不是一个喧闹的应用。温暖但不甜腻。专注但不冷峻。

## 反参考

- 传统 IDE（VS Code、Sublime Text）：**不要 IDE 式密集工具栏**——无复杂按钮组、无状态面板堆叠、无满屏配置项。文件树/标签页/大纲可以有，但**按需出现，默认克制**（侧栏可隐藏、标签条极简）。
- 笔记类应用（Notion、Obsidian）：无块编辑器、无数据库、无插件。
- 典型的「开发者工具」审美：灰暗的面板、锐利的边角、密集的信息。

## 设计原则

1. **消失的设计**：不需要时界面主动退让。内容永远是主角。
2. **克制中的温暖**：温暖来自用心的间距、排版与配色——而非装饰性堆砌。
3. **阅读优先**：布局为舒适的长文阅读而优化。排版与间距的优先级高于编辑能力。
4. **一致的材质感**：每一处表面都应像一件连贯的实体物件，而不是一组分离的面板。
5. **零摩擦交互**：保存、主题切换、文件操作都应即时、毫不费力。

## 无障碍与包容

符合 WCAG AA 标准。正文对比度 ≥ 4.5:1。支持 prefers-reduced-motion。所有主题中提供足够的颜色对比度。
