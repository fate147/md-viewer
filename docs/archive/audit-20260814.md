### 2.1 F13/F14 在架构模块表中无归属
requirements P1 的 F13（图片插入）、F14（全项目搜索），在 `architecture.md` §3 全部 16 个模块里没有任何承接模块。P1 可以缓做，但架构文档应注明「未规划模块，实施时先补设计」，或明确移出 2.0 范围。

### 2.2 session.py 文本存储设计有二义性
`architecture.md:119` TabState.text 注释「编辑缓冲（**或直接存 Tk Text 控件**）」：
- 若存 Tk Text 控件 → core 层依赖 Tkinter，违反硬约束 1（core 零 UI 依赖）；
- 若存 str → 每次击键全量同步大文件文本 + 防抖渲染全量重读，性能与一致性都缺方案。
- **建议**：明确「Text 控件由 ui 层持有，session 只存 path/encoding/dirty/cursor 元数据；撤销栈靠每标签独立 Text 控件天然隔离」。
